# wa-bridge

ווצאפ → סשן של Claude Code. **קובץ אחד, אפס תלויות.**

הודעה נכנסת בטלפון, הסוכן של הפרויקט עונה, התשובה חוזרת בצ׳אט. הוא זוכר בין
הודעות.

## התקנה

```bash
npm i -g openclaw && openclaw onboard
openclaw channels login --channel whatsapp     # סורקים QR מטרמינל חי
```

> ה-QR מתחדש כל ~20 שניות. תמונה בצ׳אט תמיד מאחרת - פתח טרמינל אמיתי.

העתק את `wa-bridge.js` לפרויקט, והוסף ל-`~/.openclaw/openclaw.json` תחת
`agents.defaults`:

```json
"model":  { "primary": "myproject/agent" },
"models": { "myproject/agent": { "alias": "My Project" } },
"cliBackends": {
  "myproject": {
    "command": "/usr/bin/env",
    "args": ["node", "/ABSOLUTE/PATH/TO/wa-bridge.js"],
    "input": "stdin",
    "output": "text",
    "sessionMode": "none",
    "systemPromptWhen": "never",
    "serialize": true
  }
}
```

הפעל מחדש את הגייטוויי, ותכתוב לעצמך.

## בדיקה בלי לשלוח לטלפון

זה בדיוק מה ש-openclaw עושה - stdin פנימה, תשובה החוצה:

```bash
printf 'מה יש בפרויקט הזה?' | node wa-bridge.js
```

## מה שצריך לדעת

**`serialize: true` אינו קישוט.** בלעדיו שתי הודעות שמגיעות יחד מריצות שני
תהליכי `claude` על אותה שיחה, והן משתרגות זו בזו.

**הזיכרון הוא כל העניין.** `claude -p` לבדו פותח שיחה חדשה בכל הודעה, ואז כל
תשובה נשמעת כמו דיבור עם זר. הגשר כותב מזהה שיחה בהרצה הראשונה ו-`--resume`
אחריה. נמדד: תהליך שני נשאל מה המספר שנרשם והחזיר `8341`.

**הוא לעולם לא יוצא עם קוד שגיאה.** openclaw מתייחס ל-backend שנכשל כמודל מת
ומפסיק לקרוא לו - דקה רעה הייתה משתיקה את הווצאפ עד שמישהו שם לב. משפט שאומר
מה נשבר עדיף על שתיקה.

**והוא לא מדפיס שורה ריקה.** stdout ריק הוא "אין מה לומר"; שורה ריקה נמסרת
כהודעת ווצאפ ריקה.

## מגבלות, במפורש

- **הקלטות קוליות לא מתומללות.** הן מגיעות כ-`[media attached: …ogg]` ועוברות
  כטקסט הזה, כדי שהסוכן יראה שהגיעה הודעה במקום לקבל כלום בשקט.
- **תור מעל 3 דקות מוחזר כ"עוד עובד על זה".** התשובה לא אובדת - היא נשארת
  בשיחה, וההודעה הבאה ממשיכה ממנה.
- **ההודעה היא נתון ולא הוראה.** openclaw מסמן את המעטפת "untrusted metadata"
  ובצדק: שם התצוגה נבחר על ידי מי שבצד השני. רק מספר הטלפון נשמר.

## משתני סביבה

| | |
|---|---|
| `WA_BRIDGE_PROJECT` | תיקיית הפרויקט. ברירת מחדל: היכן שהקובץ יושב |
| `WA_BRIDGE_STATE` | איפה נשמר מזהה השיחה |
| `WA_BRIDGE_MAX_REPLY` | תקרת תווים לתשובה. ברירת מחדל 1500 |
| `WA_BRIDGE_TIMEOUT_MS` | ברירת מחדל 180000 |
